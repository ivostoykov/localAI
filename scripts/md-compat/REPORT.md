# Issue #18: Markdown conversion and rendering compatibility

Generated by `node scripts/md-compat/run.mjs`. Regenerate rather than edit by hand.

Scope: synthetic fixtures only. This is a compatibility inventory, not a measure of extraction or rendering accuracy on real pages, and not a model-quality evaluation.

## Method

- `src/jslib/content-extractor.js` and `src/jslib/solomd2html.js` are loaded unmodified in jsdom (`scripts/md-compat/harness.mjs`).
- `hasVisibleText()` and `getARIAContext()` are copied verbatim from `src/content.js` (`:388`, `:301`) because `content.js` cannot be loaded on its own; keep the copies in step.
- The extractor runs on a clone of `document.body` with `detectMainContent()` applied, then `extractEnhancedTextStructure()` and `formatEnhancedPageContent()`.
- The renderer runs with `streamReply:false`, as in `tests/solomd2html.test.js`.
- Turndown is an unmodified pinned evaluation copy, fetched on first run into `scripts/md-compat/.cache/` and hash-checked. It is not vendored, installed or shipped.

## Defects that are not syntax gaps

- Absolute links are corrupted for valid Markdown: the `renderInline()` bare-URL rule (`solomd2html.js:433`) runs after the link rule (`:431`) and rewrites the href it just created. Relative links are unaffected. Fixtures R2, R9a; extraction fixture E14 for the same URL shape.
- Nested lists and `pre > code` are duplicated by the extractor (`content-extractor.js:208-234`, `:332-356`); fixture E2, E7, E15.
- Document order is lost within a section (`content-extractor.js:473-521`); fixture E8.
- Ordered-list start is dropped (`content-extractor.js:388-402`); fixture E3.

## Limits

- jsdom is not a browser. The defects recorded here are DOM-order and string-replacement facts, so layout independence is expected, but no browser run was made in this assessment.
- No live page, no site-specific extractor and no model-answer quality was measured.
- Header-less tables were checked against the gfm plugin only; a custom rule was not implemented.
- The implementation-cost figure in the issue discussion is an estimate and has not been validated.
