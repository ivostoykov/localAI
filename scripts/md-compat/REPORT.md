## Method

- `src/jslib/content-extractor.js` and `src/jslib/solomd2html.js` are loaded unmodified in jsdom (`scripts/md-compat/harness.mjs`).
- `hasVisibleText()` and `getARIAContext()` are sliced out of `src/content.js` by function name and evaluated as-is, because `content.js` cannot be loaded on its own. No logic is copied.
- jsdom has no `CSS.escape`, so the harness supplies a CSSOM-shaped polyfill for that one missing global. Checks P1 and P2 exercise the aria paths.
- The extractor runs on a clone of `document.body` with `detectMainContent()` applied, then `extractEnhancedTextStructure()` and `formatEnhancedPageContent()`.
- The renderer runs with `streamReply:false`, as in `tests/solomd2html.test.js`.
- Turndown is an unmodified pinned evaluation copy, fetched on first run into `scripts/md-compat/.cache/` and hash-checked. It is not installed, vendored or shipped.

### R15 — Ordered list with a lazy continuation line

Generated input Markdown:

~~~markdown
1. First item
   continued on next line
2. Second item
~~~

Generated rendered structure:

~~~text
ol(start=1)
  li: <span>First item</span>
p: <span> continued on next line</span>
p: <span>2. Second item</span>
~~~

Manual grade: `bug`. The continuation line becomes a paragraph and the following ordered item stops being list content.

### R16 — Backslash escapes for Markdown punctuation

Generated input Markdown:

~~~markdown
A \*literal\* star and \# hash and snake\_case.
~~~

Generated rendered structure:

~~~text
p: <span>A \*literal\* star and \# hash and snake\_case.</span>
~~~

Manual grade: `unsupported`. Backslash escapes are not decoded, so "\*" and "\#" would display with the backslash. Relevant if escaped text reaches the renderer.

## Defects that are not syntax gaps

- Absolute links are corrupted for valid Markdown: the `renderInline()` bare-URL rule (`solomd2html.js:433`) runs after the link rule (`:431`) and rewrites the href it just created. Relative links are unaffected. Fixtures R2, R9a; extraction fixture E14 for the same URL shape.
- Nested lists and `pre > code` are duplicated by the extractor (`content-extractor.js:208-234`, `:332-356`); fixtures E2, E7, E15, confirmed by checks E2, E7, E15.
- Document order is lost within a section (`content-extractor.js:473-521`); fixture E8, confirmed by check E8.
- Ordered-list start is dropped (`content-extractor.js:388-402`); fixture E3, confirmed by check E3.

## Limits

- jsdom is not a browser. The defects recorded here are DOM-order and string-replacement facts, so layout independence is expected, but no browser run was made in this assessment.
- No live page, no site-specific extractor and no model-answer quality was measured.
- Header-less tables were checked against the gfm plugin only; a custom rule was not implemented.
- The implementation-cost figure in the issue discussion is an estimate and has not been validated.
- Grades are tied to the source hashes above; a run against different sources warns when they no longer match.
